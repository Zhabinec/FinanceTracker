# Подключение Telegram

Рабочая ветка — `codex/platform-telegram`. Финансовая логика и API остаются общими
с браузерной версией. Токен бота сам по себе не подключает Telegram-вход и не
публикует приложение.

## Локальная настройка бота

1. Если токен попал в чат, исходники или другие доступные места, перевыпустить
   его в официальном [BotFather](https://t.me/BotFather): `/revoke`, выбрать бота
   и получить новый токен по подсказкам BotFather.
2. В Windows PowerShell 5.1 или PowerShell 7 из корня репозитория выполнить:

   ```powershell
   ./scripts/configure-telegram.ps1
   ```

3. Ввести новый токен в скрытом приглашении. В чат и исходники его вставлять не нужно.

Скрипт обращается только к `https://api.telegram.org`, проверяет бота методом
[getMe](https://core.telegram.org/bots/api#getme) и сохраняет `Telegram:BotToken`
в .NET User Secrets проекта Finance.Api. JSON передаётся CLI через stdin;
токен не нужен в аргументах командной строки. Скрипт показывает только username
бота и не печатает ошибки HTTP с URL, содержащим секрет. Настройки других
секретов API сохраняются.

[.NET User Secrets](https://learn.microsoft.com/aspnet/core/security/app-secrets?view=aspnetcore-10.0)
находятся вне репозитория, но не шифруются: это средство локальной разработки.
На хостинге токен будет задаваться секретной переменной `Telegram__BotToken`.
Не использовать `dotnet user-secrets list` для скриншотов или вывода в чат.

Скрипт проверяет доступ к Bot API. Он не отправляет сообщения, не меняет меню
бота и не делает приложение доступным из Telegram.

## Следующие этапы

1. Реализовать вход Mini App: backend проверяет подписанный `initData` и его срок,
   определяет пользователя и выдаёт сессию. `initDataUnsafe` не является доказательством личности.
2. Подключить Telegram SDK, адаптацию интерфейса и обработку запуска вне Telegram.
3. Разместить приложение и PostgreSQL, получить публичный HTTPS URL.
4. В BotFather настроить Main Mini App и кнопку меню с этим URL.
5. Проверить вход и изоляцию данных на телефоне и в Telegram Web/Desktop.

Эти этапы ещё не реализованы одной настройкой токена. Способ привязки существующего
email-аккаунта к Telegram нужно сохранять явным: совпадение username/имени не даёт
доступ к существующим финансовым данным.
